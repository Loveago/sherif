NOTES FOR CLAUDE IMPLEMENTATION:

1. This is a comprehensive e-commerce platform focused on digital products 
   (data packages, top-ups) in Ghana with mobile money payment integration.

2. Key differentiators:
   - Agent/Affiliate system with custom storefronts
   - Commission and payout management
   - Multiple account types with role-based pricing
   - Real-time chat with encryption
   - External API integration for order processing

3. Database relationships are complex:
   - Users can be customers, agents, or admins
   - Products can have multiple pricing tiers (role-based)
   - Orders track original pricing, not live pricing
   - Referral orders link to main orders and track commission

4. Security considerations:
   - JWT token validation on all protected routes
   - Role-based middleware for admin access
   - Password hashing and validation
   - Message encryption for chat
   - API key validation for external access

5. Production deployment should include:
   - Database backups
   - Error logging and monitoring
   - Caching for frequently accessed data
   - Rate limiting on API endpoints
   - Regular security audits

6. Testing requirements:
   - Unit tests for services
   - Integration tests for API endpoints
   - Payment gateway testing (test mode)
   - Real-time communication testing
