# DATAHUB GHANA

## Enterprise Data Bundle Marketplace, Agent Platform & Management System

# PROJECT OVERVIEW

Build a complete enterprise-grade full-stack data bundle marketplace and management platform for Ghana.

The platform should allow customers, agents, resellers, and administrators to buy, process, manage, fulfill, and track mobile data bundle orders across all major Ghanaian networks.

Supported Networks:

* MTN Ghana
* Telecel Ghana
* AirtelTigo Ghana

This should be a modern SaaS platform capable of handling thousands of transactions daily.

The platform must support:

* Wallet funding
* Data purchases
* Bulk data purchases
* Agent storefronts
* Commission management
* Order processing
* Refunds
* Complaints
* Announcements
* Webhooks
* Provider integrations
* Analytics
* Enterprise administration

# WALLET-FIRST SYSTEM

IMPORTANT:

This platform must use a wallet-first architecture.

Users do not purchase data directly using Paystack.

Flow:

Deposit Funds
→ Wallet Credited
→ Buy Data Bundle Using Wallet Balance

Benefits:

* Easier refunds
* Easier accounting
* Easier bulk purchases
* Easier commission tracking
* Better user experience

---

# PAYMENT SYSTEM

Supported Payment Methods Only:

## Paystack

Features:

* Deposit Funds
* Payment Verification
* Webhooks
* Transaction History
* Automatic Wallet Credit

Flow:

1. User enters amount.
2. Paystack payment initialized.
3. User completes payment.
4. Payment verified.
5. Wallet credited automatically.

---

## MTN Mobile Money

Features:

* MTN MoMo Collection API
* Payment Requests
* Verification
* Transaction Tracking

Flow:

1. User enters MTN number.
2. System sends payment prompt.
3. User approves payment.
4. Payment verified.
5. Wallet credited automatically.

# DATA PRODUCT SYSTEM

Products are NOT generated automatically.

Administrators will manually create all products.

Example:

MTN

* 1GB — GHS 4.50
* 2GB — GHS 7.00
* 3GB — GHS 10.00
* 5GB — GHS 15.00
* 10GB — GHS 28.00

Telecel

* 1GB — GHS X.XX
* 2GB — GHS X.XX
* 5GB — GHS X.XX

AirtelTigo

* 1GB — GHS X.XX
* 2GB — GHS X.XX
* 5GB — GHS X.XX

All products must come from the database.

No hardcoded products.

No hardcoded pricing.

Everything should be dynamic.

---

# PRODUCT PURCHASE FLOW

1. User selects network.
2. User selects bundle.
3. User enters phone number.
4. System validates balance.
5. Wallet debited.
6. Order created.
7. Fulfillment queue triggered.
8. Provider processes order.
9. Status updated.

Order Statuses:

* Pending
* Processing
* Successful
* Failed
* Refunded

---

# BULK DATA PURCHASES

Support:

* CSV Upload
* XLSX Upload

Fields:

* Phone Number
* Product

Flow:

1. Upload file.
2. Validate records.
3. Preview records.
4. Calculate cost.
5. Create order batch.
6. Process through queue.

Batch Statuses:

* Pending
* Running
* Completed
* Failed
